## Course-wide / template observations (log once; don't re-flag per zone)

- **Script zones — "build" ≈ "learn".** In alphabet zones the
  learn→recognize→build→mix→checkpoint template has no sentences to "build", so
  `build` just repeats the recognition drill. Defensible for letter
  memorisation; noted so it isn't re-raised for every script zone.
  _(seen: ur Z1; expect the same in every course's script zone.)_
- **Script zones — letter-question phrasing.** MC reuses the word templates
  "What does this mean?" (glyph→gloss) and "Which one means 'letter: X'?". For
  letters these read a little oddly ("means 'letter: alif'"). Not wrong — but a
  letter-specific template ("Which letter is this?" / "Which one is X?") would
  read better. **Style call for Ruan**: changing one course only makes it
  inconsistent with the others, so this wants a course-wide decision.

## Urdu (ur)

- **Z1 · `ur_c2` "Dots decide"** — the intro note explains only the boat-skeleton
  family (ب پ ت ٹ ث), but the topic also teaches ی ے ھ, which the note never
  mentions (they're only drilled), and ھ is properly explained only later in
  `ur_c6`. Coherence gap from the generator's fixed 5-vocab-per-topic grouping.
  Two ways to fix: (a) patch the note to name the extra letters, or (b) regroup
  letters so each topic's five share a theme — (b) is cleaner but touches
  vocab/SYM/the alphabet page. **Flagging for a design call** rather than
  patching unilaterally.
